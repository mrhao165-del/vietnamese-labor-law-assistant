# v1.0.0 portfolio release notes

Status: **technical and human review complete; remediation merged into main; manual release actions
remain; not published**. Tag and GitHub Release do not yet exist.

## Overview and capabilities

This release packages a source-grounded Vietnamese Labour Code information assistant with a React
browser, FastAPI/SQLite backend, hybrid Qdrant/BM25S retrieval, locked reranker, finite LangGraph
Agent, project-owned MCP stdio tools, deterministic Article 20/35 calculator, and fail-closed
citation verification.

## Architecture

Nginx serves the React/Vite/TypeScript application and proxies same-origin requests to FastAPI.
FastAPI owns local SQLite persistence and invokes `AgentService`. The Agent launches retrieval and
calculator MCP servers as stdio child processes. Retrieval uses Qdrant plus Vietnamese lexical
retrieval and reranking. Final claims pass the guardrail before return/persistence.

## Benchmark summary

On the aligned frozen DEV split, V1/V2/V3 Hit@1 is 0.8696/0.7826/0.9565; Recall@5 is 1.0000 for all;
MRR is 0.9217/0.8841/0.9783. V3 is the locked `R2_H2_C10_O5_L512_B1` production configuration.
V4 preserves the 40-case Agent and 40-case guardrail offline contract suites and adds a final
87-attempt live Docker/LLM CPU targeted evaluation. It is not a retrieval ranking. See
`docs/evaluation/final_agent_guardrail.md`.

## Test and Docker verification

Final validation observed 361 Python tests passing at 85.92% coverage, Ruff and Pyright passing, two
production MCP stdio demos passing, frontend typecheck/lint/build passing, and zero production npm
audit vulnerabilities. A no-cache CPU-only Compose build started healthy; public health, readiness,
frontend, SPA fallback, and OpenAPI endpoints returned 200. The four live matrices passed 87/87 in
aggregate; SQLite persisted across API restart. Mean/P95 real end-to-end CPU latency was
11.632/25.848 seconds, so complex requests may take several or tens of seconds. GPU support is not
claimed.

## Security and privacy

Secrets remain runtime-only; no key is shipped to the browser or recorded in release provenance.
MCP subprocess environments and public traces are bounded/sanitized. There is no authentication or
multi-user isolation, so this release is for local single-user use.

## Limitations and known issues

- Live Agent use requires a valid provider credential and network access.
- The corpus is a snapshot; external regulations and later amendments may be absent.
- The calculator supports only existing Article 20/35 rules.
- Fail-closed checks may decline an answer that lacks sufficient support.
- Round-2 review found 6 PASS, 2 FAIL, and 1 NEEDS_DISCUSSION. The three findings received generic
  remediation and all three round-3 rows subsequently passed independent review.
- Docker verification is CPU-only.
- V1's preserved source timing includes a mean/P95 inconsistency caused by source-runner measurement;
  Week 12 did not rewrite it.
- Required genuine UI screenshot evidence and the MIT License are complete; GitHub rendering review,
  release-prep Actions, tag, publication, and profile updates remain open manual gates.
- The project owner intentionally omitted a demo video from v1.0.0. No video or video URL is claimed.

## Setup and upgrade

For a fresh clone, copy `.env.example` to a private `.env` or use the documented external
`APP_ENV_FILE`, then run `docker compose --env-file <file> up -d --build --wait`. Existing named
volumes preserve Qdrant/SQLite state; review schema/runtime changes before reusing data from an older
checkout.
