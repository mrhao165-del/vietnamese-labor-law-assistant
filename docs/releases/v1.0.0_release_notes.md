# Vietnamese Labor Law AI Assistant v1.0.0

Status: draft release notes. The Week 12 remediation is merged into main and the project owner
confirms GitHub Actions are green. The tag and GitHub Release have not been created.

## Highlights

- React/Vite/TypeScript browser UI served by Nginx with same-origin FastAPI access.
- FastAPI with local SQLite conversation, message, and feedback persistence.
- Hybrid Vietnamese legal retrieval: BGE-M3, Qdrant, Underthesea plus BM25S, project-owned RRF, and
  bge-reranker-v2-m3 under the locked R2_H2_C10_O5_L512_B1 configuration.
- Finite LangGraph workflow using allowlisted project-owned Legal Retrieval and Legal Calculator MCP
  stdio child processes.
- Deterministic Article 20/35 calculator and fail-closed citation/semantic guardrail.

Faithfulness, response relevancy, and answer correctness are not claimed because the repository does
not contain reproducible judge-backed metrics for them.

## Limitations

- The legal corpus is a source snapshot, not every current Vietnamese legal instrument.
- This product provides legal information, not professional legal advice.
- Calculator coverage is limited to its implemented Article 20/35 rules.
- Docker verification is CPU-only. GPU support is not claimed.
- SQLite is local, unauthenticated, and single-user.
- Live answers require a valid private provider credential and network access.
