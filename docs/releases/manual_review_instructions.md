# Week 12 independent manual review

The packet contains 24 deterministic, stratified live HTTP Agent responses. Automation captured the
answers, citations, bounded excerpts, traces, verification, warnings, and latency; it did **not**
approve any row.

Open either:

- `evaluation/review/week12_manual_review_packet.html` in a browser; or
- `evaluation/review/week12_manual_review_packet.csv` in a spreadsheet using UTF-8.

For every row, compare the question, expected route/tools/legal target, system answer, citations,
bounded source excerpts, and verification result. Fill only:

- `reviewer_decision`: use a documented vocabulary such as `PASS`, `FAIL`, or `NEEDS_DISCUSSION`;
- `reviewer_name`;
- `reviewer_role` (state actual qualifications; do not imply licensure);
- `reviewed_at` in ISO 8601;
- `evidence_note`, especially for every non-PASS decision.

Review all 24 rows. Do not change the question, system answer, citations, expectations, or source
excerpts. Preserve the original packet before applying review decisions. The reviewer must be an
independent human; an AI-assisted review does not satisfy this gate.

After review, record the reviewed packet's checksum and decision counts in a new review result. Do not
overwrite historical evaluation evidence or claim legal-professional review unless the reviewer
actually has and documents that role.
