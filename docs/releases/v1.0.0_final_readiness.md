## 2. As-built architecture

Browser -> React/Vite/TypeScript -> Nginx -> FastAPI -> SQLite -> finite LangGraph Agent -> MCP stdio
Legal Retrieval and Legal Calculator -> citation/semantic guardrail -> verified public response.

The retrieval implementation is Python 3.11 with BGE-M3, Qdrant, Underthesea plus BM25S, custom RRF,
and bge-reranker-v2-m3 under locked `R2_H2_C10_O5_L512_B1`. The implemented production MCP transport
is stdio, not Streamable HTTP. Docker evidence is CPU-only.

## 11. Known limitations

- The legal corpus is a snapshot and may not contain later amendments or every legal instrument.
- The calculator only covers implemented Article 20/35 rules; it is not general legal reasoning.
- Live answers require a private provider credential and network access; CPU latency can be several or
  tens of seconds for complex requests.
- SQLite is local, unauthenticated, and single-user; auth, tenancy, migration, backup, and multi-user
  operation are out of scope.
